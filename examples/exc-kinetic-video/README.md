# 엑스퍼트컨설팅 키네틱 모션그래픽 (88초)

"직원 교육 컨설팅은 엑스퍼트컨설팅."으로 끝나는 90초 이내 모션그래픽이다. 키네틱 아트(진자·모빌·맞물린 고리)를 화면 언어로 쓰고, 코드로 프레임을 그려 MP4로 렌더한다. 시각 체계는 같은 폴더의 [DESIGN.md](DESIGN.md)에 있고, 영상은 그 파일의 `colors`를 읽어 색을 정한다.

## 1. 홈페이지 분석

### 확인 방법과 한계

- 이 작업 환경의 네트워크 정책이 `exc.co.kr`(www, m, recruit 포함)을 차단해 페이지를 직접 열지 못했다. 검색 결과에 노출된 페이지 제목·요약과 공개 기업정보로 내용을 확인했다.
- 그래서 사이트에서 **브랜드 컬러와 로고는 확인하지 못했다.** 이후 사용자가 로고 PNG(374×82)를 전달했다. 강조색을 그 로고의 초록(#009A5A)으로 바꾸고, 엔딩 카드에 로고를 작게 넣었다.

### 확인한 사실 (검색 요약 기준)

| 항목 | 내용 | 영상 반영 |
|---|---|---|
| 정체성 | "Total HR 전문 회사", 사이트 제목 "Total HR Professional 엑스퍼트컨설팅" | 고리 중앙 라벨, 엔딩 태그라인 |
| 설립 | 1994년 6월 | 1994→2026 오도미터, "30년 넘게, HR 한 길" |
| 규모 | 연간 1,000여 개 기업·공공기관과 협업 | 0→1,000+ 카운터 |
| 사업 영역 | 채용컨설팅, NCS, 진단평가, 집합교육, 원격교육(이러닝), HRD컨설팅, 연수원 | Total HR 고리의 6개 정류장 |
| 진단·평가 | K-FIT(직장 적합도), BDPI(인성), 역량면접 도구, 면접관 교육, 역량평가센터(AC/DC) | 정류장 02 태그 |
| HRD | 직무·역량 기반 교육체계 수립, 리더십(직급별·팀장 아카데미·360 다면진단) | 정류장 03·04, 모빌 장면 |
| 2025 HR FAIR | AI 활용, 온보딩, 조직활성화, 임원→팀장 3단계 리더십 | 혼돈 장면의 키워드, 모빌의 3계층 |

### 확인 필요

- 강조색 #009A5A와 로고 검정 #231815는 전달받은 로고 PNG에서 잰 픽셀값이다. 공식 CI 색상표와 대조가 필요하다. 다르면 `DESIGN.md`의 `colors`만 고치고 다시 렌더한다.
- 로고 원본 벡터(AI·EPS·SVG)는 아직 받지 못했다. 엔딩 로고는 PNG를 폭 330px로 줄여 쓰므로 이 크기에서는 흐려지지 않는다. 더 크게 쓰려면 원본 벡터가 필요하다.
- "연간 1,000여 개 기관"은 채용·기업정보 페이지 요약에서 확인한 수치다. 공식 소개 페이지 수치와 대조가 필요하다.
- 연수원 정류장은 사업 영역 목록에만 근거한다. 세부 프로그램명은 넣지 않았다.

## 2. 콘셉트

**흔들리던 질문이 멈춰 마침표가 된다.** 첫 장면의 초록 진자 추(어디서부터 시작해야 할까?)가 영상 내내 공·고리·점으로 모습을 바꾸며 이어지고, 마지막에 멈춰서 "엑스퍼트컨설팅."의 마침표가 된다.

| 흐름 | 키네틱 은유 |
|---|---|
| 질문 | 흔들리는 진자 |
| 문제 | 무질서하게 떠다니는 교육 키워드 |
| 전환 | 한 줄의 선에 키워드가 꿰인다 |
| 해법 | 선이 고리가 되고, 공이 채용→연수원 6단계를 돈다 |
| 계층 | 임원·팀장·신입이 매달린 모빌이 균형을 찾는다 |
| 근거 | 오도미터 숫자 |
| 답 | 모든 조각이 한 점으로 수렴 → 진자가 멈추고 마침표가 된다 |

## 4. 만들기

참고 레포(awesome-opus-5.5-video)의 모션그래픽 사례에서 가장 많이 쓰인 방식(코드로 프레임을 그리고 Playwright로 캡처, FFmpeg로 인코딩)을 따랐다. 외부 영상·음원 소스는 쓰지 않는다.

```bash
cd examples/exc-kinetic-video
npm install                 # playwright-core, pretendard(폰트)
npm run preview             # http://localhost:8080 에서 재생·스크럽
npm run render              # bgm.wav 합성 → out/exc-kinetic.mp4
npm run render:split        # C안(0–21초 빨강 → 21초 선부터 초록) → out/exc-kinetic-split.mp4
node render.mjs --stills 12,50,82   # 특정 시각 PNG
node render.mjs --from 29 --to 52   # 구간 미리보기(무음)
```

- Chromium이 Playwright 기본 경로에 없으면 `CHROME_PATH`로 실행 파일을 지정한다.
- 엔딩 로고: `brand/logo.svg`(우선) 또는 `brand/logo.png`를 두면 엔딩 카드의 구분선 아래에 들어간다. 로고 파일은 레포에 넣지 않는다(`brand/`는 git에서 제외). 파일이 없으면 태그라인으로 렌더한다.
- 출력: 1920×1080, 30fps, H.264 + AAC, 88초.

| 파일 | 역할 |
|---|---|
| `index.html` | 캔버스 애니메이션. `render(t)`가 시각 t만으로 프레임을 결정한다. 브라우저에서 열면 재생기 |
| `render.mjs` | 정적 서버 + Playwright 프레임 캡처 → FFmpeg |
| `bgm.mjs` | 장면 큐에 맞춘 120BPM 배경음 합성 → `bgm.wav` |
| `DESIGN.md` | 색·타이포·모션 원칙. `colors`를 바꾸면 영상 색이 바뀐다 |
| `NARRATION.md` | Eleven v4용 한국어 내레이션 대본(입력문, 큐 시트, 생성·배치·믹스 방법) |
| `narration.json` | 같은 대본의 기계용 데이터(블록, 큐별 발화 시작·허용 창·대체 문구) |
| `vo_sync.json` | 실제 Eleven v4 테이크를 큐별로 잘라 놓는 배치표(원본 구간 → 영상 시각, 믹스 설정) |
| `mix-vo.mjs` | 배치표를 적용해 내레이션·덕킹 배경음을 섞고 `out/exc-kinetic-vo.mp4`를 만든다(`npm run mix`, 테이크는 `vo/`에 둔다). C안은 `npm run mix:split` → `out/exc-kinetic-split-vo.mp4` |
| `brand/` | 사용자가 준 로고 파일 자리(`logo.svg` 또는 `logo.png`). git에서 제외한다 |

## 5. 바꾸기 쉬운 곳

- **색:** `DESIGN.md`의 `colors` (paper, ink, signal, alert, cobalt, ochre, graphite, rule). `alert`는 C안(`--accent split`, 미리보기는 `?accent=split`)에서 문제 구간에만 쓴다.
- **카피:** `index.html`의 각 장면 함수(S0–S6)에 있는 `kText(...)` 문자열. `[ ]`로 감싼 글자는 강조색이 된다.
- **로고:** `brand/logo.svg` 또는 `brand/logo.png`. 엔딩 카드 구분선 아래에 폭 330px(`DESIGN.md`의 `brand-logo`)로 들어간다.
